# WebUI Roadmap

记录 WebUI 未完善的功能（卡片页签内的 Roadmap 区块同步展示部分条目）。

## 卡片（2026-09-09 补全：编辑/删除、导出/导入、卡库、树图选点提炼）

- [x] 编辑 / 删除卡片（引擎 card_edit / card_delete 事件）
- [x] 卡片导出 / 导入 UI（导出下载 markdown；导入可粘贴或选 .md 文件）
- [x] 跨会话卡库与引用（复制导入语义：导入 = 独立副本，不随源变化）
- [x] 树图选节点点选 → 自定义提炼范围生成卡片
- [ ] 跨会话卡片实时引用（源卡片更新同步到副本，需跨文件事件订阅设计）
